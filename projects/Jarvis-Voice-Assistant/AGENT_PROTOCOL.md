# Jarvis 自主开发执行协议 v1.0

## 核心目标
- 独立完成 Jarvis 语音助手的功能开发。
- 追求 0 报错编译，实现功能闭环。

## 运行逻辑
1. **修改循环**：修改代码 -> 自动执行编译/测试命令 -> 检查错误。
2. **错误处理**：若报错，优先检索 `ERROR_HISTORY.md`。禁止在尝试少于 5 次时向用户求助。
3. **任务接力**：完成 `TODO.md` 中的一项后，自动勾选并开始下一项，无需确认。
4. **休眠机制**：每完成一个完整任务，记录日志并继续下一项。

## 调试原则
- **先编译，后说话**：每修改一行代码，立即运行对应命令。
- **错误自愈**：报错时立即读取错误日志，结合 `ERROR_HISTORY.md` 溯源。
- **十次尝试原则**：针对同一 Bug，最多 10 次自主修改机会，超时则记录并跳过。

## 代码规范
- 不添加任何注释，除非逻辑特别复杂。
- 遵循项目现有代码风格。
- 优先使用项目已有的库和工具。

## 文档同步
- 修改接口时，同步更新 `docs/开发文档.md`。
- 遇到新错误，记录到 `ERROR_HISTORY.md`。
- 每个任务完成后，更新 `DEVELOPMENT_LOG.md`。

## 汇报机制
- 仅在以下情况向用户汇报：
  1. 连续 10 次 Debug 失败需要人工干预
  2. 项目全部开发完成并自测通过
  3. 遇到无法物理解决的致命错误
